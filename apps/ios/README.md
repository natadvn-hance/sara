# Hance для iPhone

Приложение, в котором Борис говорит голосом с Лорой (по умолчанию) и с
Сарой («позови Сару»). Ядро то же, что у страницы `sara.hance.pro/talk`:
те же адреса, тот же вход паролем пульта, та же память разговора
(ADR-028, ADR-029).

## Что умеет сверх страницы в Safari

| | Страница в Safari | Приложение |
|---|---|---|
| Боковая кнопка | открывает Safari, потом страницу | сразу слушает, приложение не открывается, работает и на заблокированном телефоне |
| Dynamic Island | нет | лицо Лоры или Сары, полоски голоса, секунды «думает», первые слова ответа, кнопка «стоп» |
| Ответ, когда телефон в кармане | нет | говорит голосом и присылает уведомление; долгое нажатие открывает анимированный вид |
| Пункт управления | нет | кнопки «Говорить с Лорой» и «Говорить с Сарой» |
| Скорость | запись уходит после конца фразы | запись уходит на сервер, пока Боря ещё говорит; ответ звучит с первого предложения |

## Как поставить на свой iPhone

Вход в Apple ID и подпись делает сам Борис: это его аккаунт.

1. Поставить **Xcode** из App Store на Маке (около 3 ГБ загрузки и 10 ГБ на
   диске). При первом запуске Xcode предложит поставить iOS: согласиться.
2. В Xcode: **Xcode → Settings → Accounts → +** и войти своим Apple ID.
3. Открыть `apps/ios/Hance.xcodeproj` из папки репозитория Сары.
4. Слева нажать на синий **Hance**, затем по очереди на каждую из трёх
   целей: **Hance**, **HanceWidgets**, **HanceNotification**. На вкладке
   **Signing & Capabilities** выбрать в **Team** свою команду (для
   бесплатного Apple ID это строка с именем и словами «Personal Team»).
   Если Xcode пишет, что идентификатор `pro.hance.talk` занят, дописать к
   нему одно и то же слово во всех трёх целях, например
   `pro.hance.talk.boris`, `pro.hance.talk.boris.widgets`,
   `pro.hance.talk.boris.notification`.
5. Подключить iPhone кабелем, на iPhone нажать «Доверять этому
   компьютеру». Включить **Настройки → Конфиденциальность и безопасность →
   Режим разработчика**, телефон перезагрузится.
6. Вверху Xcode выбрать свой iPhone и нажать ▶ (Run).
7. На iPhone при первом запуске: **Настройки → Основные → VPN и
   управление устройством → Apple Development → Доверять**. Снова открыть
   Hance.
8. В Hance ввести пароль пульта, разрешить микрофон и уведомления.
9. Боковая кнопка: **Настройки → Кнопка действия → Команда → Hance →
   Говорить**. Или **Элементы управления → Hance → Говорить с Лорой**.

### Бесплатный Apple ID и платная программа

- С бесплатным Apple ID приложение работает **7 дней**. Потом iOS его не
  открывает: подключить iPhone и снова нажать ▶ в Xcode, данные и вход
  сохранятся.
- Apple Developer Program стоит **99 $ в год**. С ней приложение живёт год
  без переустановки, его можно ставить через TestFlight без кабеля, и
  становятся доступны пуши: тогда ядро сможет присылать сообщения Лоры и
  Сары и обновлять Dynamic Island, даже когда приложение закрыто. Это
  решение и покупка Бориса.

## Где граница iOS

- **Системный баннер уведомления** нарисован iOS, приложение не может его
  анимировать. Hance делает что можно: свой анимированный баннер внутри
  приложения (ответ «вырастает» из Dynamic Island и подсвечивается по
  словам, пока она говорит), свой анимированный вид уведомления при долгом
  нажатии и живую Live Activity.
- **Dynamic Island** анимирует только смену состояния (до 2 секунд на
  переход) и сама считает секунды. Полоски голоса двигаются, потому что
  приложение обновляет её пару раз в секунду, пока кто-то говорит.
- **Без пушей** (бесплатный Apple ID) уведомление и Dynamic Island живут,
  пока идёт разговор: приложение держит микрофон и звук включёнными, пока
  ждёт ответа (до шести минут). Сообщение, которое Лора или Сара начнёт
  сама, когда разговора нет, придёт только с пушами.

## Для разработки

- Проект Xcode собирается из `project.yml`: `brew install xcodegen`, затем
  `xcodegen generate` в этой папке. Готовый `Hance.xcodeproj` лежит в
  репозитории.
- Тесты логики (пауза в речи, куски ответа для голоса, WAV, ожидание
  ответа, разбор ответов ядра):
  `xcodebuild test -project Hance.xcodeproj -scheme Hance -destination 'platform=iOS Simulator,name=iPhone 17 Pro'`.
- Проверка в симуляторе без настоящего ядра: `node tools/mock-core.mjs`
  (двойник ядра на `localhost:8787`, тестовый пароль `hance-test`, голос
  Milena из macOS), приложение запускается с аргументами
  `-HanceServer http://localhost:8787`. Аргумент
  `-HanceFakeVoice /путь/к/файлу.wav` подставляет файл вместо микрофона
  (только в Debug).
- Замеры скорости: долгое нажатие на строку состояния вверху экрана. Там
  по каждому вопросу видно, сколько он говорил, сколько ждали паузу, сколько
  заняли загрузка с распознаванием, ответ Лоры или Сары и голос.
- Шрифты Onest и Martian Mono собраны из файлов сайта
  (`_1. Projects/Hance/Сайт/assets/fonts`) скриптом `tools/fonts.py`,
  иконка нарисована `tools/make-icon.swift`.
