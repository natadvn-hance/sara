# Подставной Профи.ру

Локальная копия поведения Профи.ру для тестов движка Профи-MCP (ADR-017):
вход телефоном и кодом, лента, заказ, чаты, поток событий в духе
`window.__RTP` и ответы JSON, которые страницы запрашивают сами.

Форматы здесь наши догадки. После калибровки на сервере (план M1, задача
16) они заменяются форматами из записанных обезличенных образцов
`tests/fixtures/profi/`. Классы пузырей чата взяты из v1.

Сайт слушает `127.0.0.1`, поток событий `[::1]`: два разных адреса, как
`profi.ru` и `online.profi.ru`. Управление: `addOrder`, `addMessage`,
`logout`, `ban`, `offline`, `muteRtp`, `changeLayout`.
