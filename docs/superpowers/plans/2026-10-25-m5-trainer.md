# M5 «Тренажёр и обучение»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сара учится у Бориса дёшево и под его контролем: его правки в работе становятся уроками пачками по 5, тренажёр в Mini App из пяти режимов показывает её вариант рядом с его ответом, после его «да» урок сама записывает в `sara-mind`, ночью учитель и генератор работают в своём бюджете, раз в неделю экзамен и слепой тест, а темы получают право «сама» только по его «да».

**Architecture:** Новый модуль ядра `apps/core/src/school/` (уроки, пачки, тренажёр, учитель, интервью, самостоятельность, экзамены недели, генератор, ночное расписание) и один новый файл `apps/core/src/mind/writer.ts` (писатель разума, ADR-025). Школа стоит на M4: вариант Сары пишет движок хода `planTurn`, разум ищется `MindSearch`, история берётся из `core.chat_message`, экзамен из `runExam`. Части связаны контрактами zod в `packages/shared/src/contracts/school.ts` и типами `apps/core/src/school/types.ts`, которые часть 0 кладёт первой вместе с заглушками по точным путям.

**Tech Stack:** TypeScript (Node 24), Fastify, Drizzle (Postgres 16), zod 4, vitest, grammY, `claude -p` через шлюз, git (CLI в образе ядра), React 19 + TanStack Query + Tailwind (пульт и Mini App), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-m5-trainer-design.md` (дальше «дизайн»), ADR-025, дизайн M4 `docs/superpowers/specs/2026-10-25-m4-conversation-design.md` и его план, спецификация `docs/spec/2026-10-22-sara-spec-v1.md`.

## Global Constraints

- **Разум только по «да» Бориса.** Ни одна строка кода, кроме `mind/writer.ts`, не пишет в `SARA_MIND_DIR`. Писатель берёт только предложения в состоянии `new`, связанные с уроком в состоянии `yes` (или с карточкой «Да, все» для образцов истории). Тест на каждую дорожку.
- **Синтетика не знание** (FR-TRAIN-9): писатель отклоняет запись с любым источником `sim:`; код экзамена и золотого набора не импортирует `school/generator.ts` и не читает `core.sim_dialog`; ответ специалиста из сгенерированного диалога нигде не сохраняется.
- **Тренировка не уходит клиентам** (FR-TRAIN-3): `school/` не импортирует `conversation/outbox.ts`, `leads/outbox.ts`, `profi/client.ts` (тест по импортам); номер разговора тренировки `train:<сессия>`.
- **Голос Бориса только от Бориса**: образцы, ответы «Угадай Бориса», слепого теста и материал учителя берутся только из строк `chat_message.author = 'boris'` (источники `node`, `v1`) и текстов Бориса в ходах (`boris_text`, настоящий ответ с `actual_author = 'boris'`). `unknown`, `sara_v1`, `telegram_export` никогда.
- **Экономия подписки**: ночные вызовы только P3 и через `withoutLimitWait`, внутри окна `school.night` и бюджета `school.night_units`; дневные вызовы тренажёра P1 через `withPriority(gw, 'P1')` и `withoutLimitWait`; разница вариантов только кодом.
- Тексты Борису по-русски, простым языком, без длинного тире U+2014 и среднего U+2013 (`pnpm check` ищет U+2014; в коде только `\u2014`, `\u2013`).
- Имя теста начинается с номера требования: `it('FR-TRAIN-6: …')`. Номера: FR-TRAIN-2..9, FR-SPEECH-1, FR-SPEECH-4, FR-AUTO-1..4, FR-MIND-3, FR-MIND-4, FR-UI-3, FR-UI-4, FR-NOTIF-1, FR-NOTIF-3, NFR-COST-2, NFR-PRIV-2, NFR-REL-3.
- Время в базе UTC; «день», «ночь», «неделя» по Москве (`Europe/Moscow`).
- События журнала без текста и имени клиента, только номера (ADR-022).
- Роли только через `Gateway.call`, без инструментов; имя клиента всегда в `redact.names`; файл записи разума собирает код из полей ответа, модель текст файла не пишет.
- `WORKFLOW_VERSION` не меняется; новых процессов DBOS нет: задачи школы идут тиком `school/jobs.ts` раз в минуту и строками `core.job_run`.
- Миграцию добавляет только часть 0. Номер следующий за последним в `main`; если `main` ушёл дальше, миграция генерируется заново (`pnpm --filter @sara/core exec drizzle-kit generate --name school`), ручной SQL (проверки, индексы) дописывается в неё.
- Тесты: своя база Postgres на свободном порту 54380-54389 (`docker run -d --name sara-pg-m5-<часть> -p <порт>:5432 -e POSTGRES_USER=sara -e POSTGRES_PASSWORD=sara -e POSTGRES_DB=sara pgvector/pgvector:pg16`), `DATABASE_URL=postgres://sara:sara@localhost:<порт>/sara`; контейнер убирается в конце; общую базу и Plane не трогать. Перед пул-реквестом `pnpm test` и `pnpm check` зелёные, новый CLI запускается один раз под `node --import tsx`.
- Ни один тест не ходит на Профи.ру и не вызывает Claude (`tests/fakes/fake-claude.mjs`, `FAKE_CLAUDE_OUTPUT_BY_ROLE`). Git в тестах только во временных папках (`mkdtemp`, `git init`, «удалённый» репозиторий `git init --bare` рядом).
- Границы M5: `apps/core/src/school/`, `apps/core/src/mind/writer.ts` и `mind/render.ts`, `roles/{trainer-client,trainer-coach,lesson-maker,teacher,persona-builder,dialog-generator}/`, `tests/e2e/school*.test.ts`, `apps/web/src/pages/trainer/`, `apps/web/e2e/trainer*.spec.ts`. Общие файлы только по списку дизайна, раздел 13; файлы M4 только по запросам R1-R8 дизайна (раздел 6), одной правкой, если M4 их не сделал.

## Review Focus

1. Два нажатия «Да» на один урок и «Все да» поверх уже решённых уроков: один коммит, каждое предложение записано один раз. Тест в Task B2 и A4.
2. В пачке урок с источником `sim:` и урок с ценой, которой нет в словах Бориса: оба отклонены с причиной, остальные три записаны одним коммитом. Тест в Task B1, B2.
3. Тренировка в каждом режиме: ноль вызовов `profi.send_message`, ноль строк `outbox`. Тест в Task C7.
4. Тема из `LOCKED_TOPICS`: серия 50 одобрений не даёт предложения, `PUT /api/autonomy/price {level: 'self'}` отвечает 400. Тест в Task F2, F3.
5. «Угадай Бориса» и слепой тест: образец, сделанный из того же чата, не попадает в поиск варианта Сары. Тест в Task C5.
6. Бюджет: задача с прогнозом больше остатка пропущена с причиной; `limit_reached` за 12 часов пропускает всю ночь; вызовы ночи P3. Тест в Task H1.
7. Перезапуск посреди записи в разум: незакоммиченные файлы отброшены, повтор пишет те же записи один раз. Тест в Task B2.
