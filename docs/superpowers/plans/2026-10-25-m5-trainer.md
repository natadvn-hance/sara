# M5 «Тренажёр и обучение»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сара учится у Бориса дёшево и под его контролем: его правки в работе становятся уроками пачками по 5, тренажёр в Mini App из пяти режимов показывает её вариант рядом с его ответом, после его «да» урок сама записывает в `sara-mind`, ночью разбор уроков, учитель и генератор работают в своём бюджете, раз в неделю экзамен и слепой тест, золотой набор сторожит уроки, а темы получают право «сама» только по его «да».

**Architecture:** Новый модуль ядра `apps/core/src/school/` (уроки, пачки, тренажёр, учитель, интервью, самостоятельность, экзамены недели, золотой набор, генератор, ночное расписание, счёт сообщений) и писатель разума в `apps/core/src/mind/` (`writer.ts`, `render.ts`, `guard.ts`, `git.ts`, ADR-025). Школа стоит на M4: вариант Сары пишет движок хода `planTurn`, разум ищется `MindSearch`, история берётся из `core.chat_message`, экзамен из `runExam`. Части связаны контрактами zod в `packages/shared/src/contracts/school.ts` и типами `apps/core/src/school/types.ts`, которые часть 0 кладёт первой вместе с заглушками по точным путям.

**Tech Stack:** TypeScript (Node 24), Fastify, Drizzle (Postgres 16), zod 4, vitest, grammY, `claude -p` через шлюз, git (CLI в образе ядра), React 19 + TanStack Query + Tailwind (пульт и Mini App), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-m5-trainer-design.md` (дальше «дизайн»), ADR-025, дизайн и план M4 (ветка `claude/m4-conversation-2cad67`), дизайн M7 (раздел 7, вход Mini App), спецификация `docs/spec/2026-10-22-sara-spec-v1.md`.

## Global Constraints

- **Разум только по «да» Бориса.** Ни одна строка кода, кроме писателя (`apps/core/src/mind/writer.ts` и его помощников), не пишет в `SARA_MIND_DIR`. Писатель берёт только предложения `new`, чей урок в состоянии `yes` (или карточка «Да, все»). Тест на каждую дорожку.
- **Синтетика не знание** (FR-TRAIN-9): писатель отклоняет запись с любым источником `sim:`; урок из карточки с источником `sim:` не даёт образца; учитель не видит сгенерированных реплик; код экзамена и золотого набора не импортирует `school/generator.ts` и не читает `core.sim_dialog`; ответ специалиста из сгенерированного диалога нигде не сохраняется.
- **Тренировка не уходит клиентам** (FR-TRAIN-3): `school/` не импортирует `conversation/outbox.ts`, `leads/outbox.ts`, `profi/client.ts` (тест по импортам); ход тренировки `train:<сессия>:<n>`.
- **Голос Бориса только от Бориса**: образцы, «Угадай Бориса», слепой тест, золотой набор и материал учителя берутся только из строк `chat_message.author = 'boris'` (источники `node`, `v1`), из `conv_turn.boris_text` и из настоящего ответа с `actual_author = 'boris'`. `unknown`, `sara_v1`, `telegram_export` никогда. Уроки `edit` и `say` и «Хорошо» работают и в тени: им автор сообщения в чате не нужен (дизайн 5.1).
- **Экономия подписки**: ночные вызовы только P3, через `withoutLimitWait`, внутри окна `school.night` и бюджета `school.night_units`; вывод урока из работы пишется ночью; днём модель зовёт только тренажёр (P1, `withoutLimitWait`); разница вариантов только кодом; вызовы P3 не занимают последний слот шлюза.
- **Не больше 3 сообщений школы в день** по её инициативе (`school.messages_per_day`), остальное строкой в вечерней сводке; ночью сообщений школы нет.
- **Номера записей из уроков** только по `lesson.n` (bigserial), никогда по началу uuid v7.
- Тексты Борису по-русски, простым языком, без длинного тире U+2014 и среднего U+2013 (`pnpm check` ищет U+2014; в коде только `\u2014`, `\u2013`).
- Имя теста начинается с номера требования: `it('FR-TRAIN-6: …')`. Номера: FR-TRAIN-2..9, FR-SPEECH-1, FR-SPEECH-4, FR-AUTO-1..4, FR-MIND-3, FR-MIND-4, FR-UI-3, FR-UI-4, FR-NOTIF-1, FR-NOTIF-3, NFR-COST-2, NFR-PRIV-2, NFR-REL-2, NFR-REL-3, NFR-SEC-1.
- Время в базе UTC; «день», «ночь», «неделя» по Москве (`Europe/Moscow`).
- События журнала без текста и имени клиента, только номера (ADR-022).
- Роли только через `Gateway.call`, без инструментов; имя клиента всегда в `redact.names`; файл записи разума собирает код из полей ответа, модель не выбирает ни текст файла, ни его путь.
- `WORKFLOW_VERSION` не меняется; новых процессов DBOS нет: задачи школы идут тиком `school/jobs.ts` раз в минуту и строками `core.job_run`.
- Миграцию добавляет только часть 0. Номер следующий за последним в `main` (M3 0008, M4 следом); если `main` ушёл дальше, миграция генерируется заново (`pnpm --filter @sara/core exec drizzle-kit generate --name school`), ручной SQL (проверки, индексы) дописывается в неё.

Перед пул-реквестом `pnpm test` и `pnpm check` зелёные, новый CLI запускается один раз под `node --import tsx`.

## Review Focus

1. Тень: Борис нажал «Изменить» на черновике, а ответ в чате с автором `unknown`: урок `edit` есть, одобрения по настоящему ответу нет. Тест в Task A5.
2. Два нажатия «Да» на один урок, «Все да» поверх решённых, падение между коммитом и базой: один коммит, каждое предложение записано один раз. Тест в Task B2, A4.
3. В пачке урок с источником `sim:`, урок с ценой, которой нет в словах Бориса, и черновик учителя с номером `../x`: все три отклонены с причиной, остальные записаны одним коммитом. Тест в Task B1, B2.
4. Десять уроков в одну миллисекунду дают десять разных номеров записей и путей предложений. Тест в Task A1.
5. Разработка отправила коммит в `sara-mind`, ночной обмен прошёл, Борис нажал «Отменить» под вчерашней пачкой: откат работает. Тест в Task B4.
6. Тренировка в каждом режиме: ноль вызовов `profi.send_message`, ноль строк `outbox`. Тест в Task C7.
7. Тема из `LOCKED_TOPICS`: серия 50 одобрений не даёт предложения, `PUT /api/autonomy/price {level: 'self'}` отвечает 400. Тест в Task F2, F3.
8. «Угадай Бориса», слепой тест и золотой набор: образец того же чата не виден Саре, чат одного запаса не попадает в другой. Тест в Task C5, G0, G4.
9. Бюджет: задача сверх остатка пропущена с причиной; `limit_reached` у модели за 12 часов пропускает задачи этой модели; ночные вызовы идут P3 и не берут последний слот. Тест в Task 0.3, H1.
