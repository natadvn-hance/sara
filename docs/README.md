## 2. Разбор списка артефактов (22.10.2026)

Борис прислал список из 33 артефактов по шести этапам. Итог сверки:

| Итог | Сколько | Какие |
|---|---|---|
| Уже были | 5 | PRD и SRS (спецификация), RFC (дизайн v3), ADR, C4 |
| Дописаны | 5 | дорожная карта, словарь данных, DoD, стратегия тестирования, схемы развёртывания |
| Сделаны новые | 18 | видение и границы, карта историй, бэклог, профили, CJM, потоки, дизайн-система, контракты (вместо OpenAPI руками), матрица трассируемости, техрадар, модель угроз, план переноса, DoR, чек-листы приёмки, онбординг разработчика, инструкции на случай сбоя, список изменений, шаблон разбора сбоя |
| Позже, в своей вехе | 3 | каркасы экранов (перед вехой с экраном), кликабельный прототип (перед M5 и M7), отчёт покрытия (автоматически с M0) |
| Не нужны | 2 | Lean Canvas или BMC (Сара не продаётся; вместо него экономика воронки), BRD (дублирует видение и спецификацию) |

Добавлено сверх списка, потому что Сара это продукт на ИИ: пресс-релиз из
будущего (Amazon), план оценки Сары с золотым набором и классами ошибок,
цели надёжности с бюджетом ошибок (Google SRE), обезличивание перед
моделью и вопросы юристу, ходячий скелет в M0, роли модели как
контракты, флаги переключения по частям.
