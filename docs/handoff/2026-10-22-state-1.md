## 7. Архитектура коротко

- **Ядро** (TypeScript, Node 24, Fastify, Postgres 16 и pgvector, DBOS):
  домен и машина состояний (этап, владелец, чей ход), движок правил,
  устойчивые процессы, шлюз модели, мозг, школа, направления, аналитика,
  API пульта, бот grammY.
- **Разум**: git-репозиторий файлов `sara-mind` плюс индекс; поиск
  полнотекстовый по-русски и локальные векторы `multilingual-e5-small`.
- **Шлюз модели**: роли через `claude -p` с `--system-prompt-file`,
  `--json-schema`, `--tools ""`, `--no-session-persistence`, приоритеты
  P0-P3, 2 вызова параллельно, учёт лимита, учёба ночью 01:00-07:00.
- **Профи-MCP** на российском узле: живая вкладка на аккаунт; чтение через
  события `window.__RTP` и данные из ответов сайта, разметка запасным
  путём; действия через интерфейс (клики, набор), проверка экраном; живой
  вход; первичное хранилище; калибровка первой в M1.
- **Пульт**: React, веб и Mini App из одного кода, интерфейс по OOUX.
- **Цикл ответа клиенту**: услышать, вспомнить, понять смысл и тон,
  сказать голосом Бориса, проверить (факты, роботность), правила,
  отправить с паузой 1-4 минуты и ожиданием «печатает», научиться.
- **Обучение**: уроки из правок, тренажёр (5 режимов), ночной учитель,
  экзамен 60 сценариев как сторож выкладки, генератор диалогов; без
  дообучения модели.
- **Направления**: система оценки (условия, веса, балл, обоснование),
  калибровка на 20 заявках до 85% согласия, формат отклика, кейсы,
  маршрутизатор (один заказ, один аккаунт).
- **Вехи**: M0 фундамент (на Маке, без серверов) → M1 Профи-MCP (нужен
  российский узел) → M2 заявка в одно нажатие (нужен узел ядра и новый
  бот) → M3 направления → M4 разум и разговор → M5 тренажёр и обучение →
  M6 встречи и итоги → M7 пульт и переключение с v1 → M8 второй аккаунт.

## 8. Что выяснило исследование

**Профи.ру:**
- Публичного API для специалистов нет.
- Справка «Что значит рейтинг отклика»: место отклика задаёт только
  рейтинг анкеты; клиент рейтинг не видит, отклики видит в порядке
  поступления. Справка о статистике: если заказ подходит многим, его
  сначала показывают тем, кто чаще договаривается. Отсюда рычаги: скорость
  и доля договорённостей.
- Кабинет специалиста подключается к каналу `online.profi.ru`
  (`window.__RTP`). Публичные скрипты `profi.ru/jqs/msngr/msngr_nk.js`,
  `msngr_unread_subscription.js` (событие `MSG_CHAT_NOTIFY` с
  `notShownCount`) и `profi.ru/static/assets/js/backIsOnlineChecker.bundle.js`
  перечисляют типы событий, среди них: `MSG_MESSAGE`, `MSG_MSG_RECEIVED`,
  `MSG_CHAT_RECEIVED`, `MSG_IS_WRITING_TO_CHAT`, `MSG_CHAT_WAS_READ`,
  `MSG_CHAT_STATUS_CHANGED`, `MSG_ORDER_CONTENT_CHANGED`,
  `MSG_CHAT_ORDER_NOTIFY`, `ORDER_FORM_NOTIFY`,
  `MSG_MESSENGER_UNREAD_NOTIFY`, `MSG_BAN_PROFILE`, `GQL_EXEC`. Что из
  этого реально приходит специалисту, снимет калибровка в M1.
- Проверено без входа в аккаунт (публичные скрипты и кэш старого браузера
  на Маке). **Никогда не открывать Профи.ру сессией демона во втором
  браузере**: 29.09 это убило сессию.
- Правила о нескольких аккаунтах публично не найдены.

**Claude по подписке:**
- Официальная справка Anthropic «Use the Claude Agent SDK with your Claude
  plan»: `claude -p` и Agent SDK расходуют лимиты подписки; с 07.10.2026
  планы Max и Team ещё и получают ежемесячные API-кредиты.
- `--bare` требует ключ API, поэтому на подписке не использовать; изоляция
  через свою рабочую папку роли, `--setting-sources project`,
  `--strict-mcp-config`, `--tools ""`.
- Долгий токен для сервера: `claude setup-token` →
  `CLAUDE_CODE_OAUTH_TOKEN`.
- Модели и цены по справке навыка claude-api на 06.10.2026: Opus 5.5,
  Sonnet 5.5, Haiku 5.5. Дообучение Claude клиентам недоступно.

**Закон:** ст. 18 ч. 5 152-ФЗ, первая запись данных граждан РФ в базу в
России; копия за рубеж по ст. 12 с уведомлением Роскомнадзора; КоАП 13.11
ч. 8: 1-6 млн ₽ юрлицам и ИП, повторно 6-18 млн ₽.

**Аналоги и методы, на которые опирается дизайн:** Intercom Fin
(процедуры, симуляции), Decagon (процедуры агента), Sierra τ-bench
(модель-клиент), Hyperbound (тренировки продаж с ИИ), GigRadar (профили и
шаблоны откликов, скорость), Clay (система оценки из описания с
калибровкой), OOUX (карта сущностей), whatsapp-web.js (настоящий
веб-клиент и данные из страницы), DBOS (устойчивые процессы), GEPA
(улучшение инструкций по провалам), Zep (временная память), модель C4,
исследования о подражании стилю и паузах в ответах.

**Цифры v1 (сервер, 21.10):** 4369 заявок с 09.09; 394 подошли; 26
оплаченных откликов на 3277 ₽; 23 разговора, 16 ответили (70%); 0 встреч
