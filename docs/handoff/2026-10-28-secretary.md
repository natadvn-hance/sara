# Секретарь (28.10.2026): свободный разговор с Сарой в боте

Ветка `claude/sara-chat`, рабочая копия `.claude/worktrees/sara-chat`, от main 3e53d2de. Решение: ADR-027.
История: ST-M7-09 (FR-NOTIF-4, FR-NOTIF-1). На сервер не выложено: выкладка только после «выкладывай» Бориса.

## Что сделано

- Роль `roles/secretary` (Opus, `effort: medium`, P0, 4 минуты). Характер и правила общения взяты из старой Сары
  (`~/(SaraAI)Профи.Ру — бот /CLAUDE.md`): от первого лица, по-русски, без длинного тире, ссылка на заявку.
- Шлюз: `gateway.converse(role, input, {redactor, mcp, maxBudgetUsd})`. Та же очередь, тот же лимит по модели и
  журнал `model_call` (роль `secretary`, в `model.called` ещё `costUsd` и `turns`). Флаги CLI:
  `buildConverseArgs` (`--tools ""`, `--mcp-config`, `--strict-mcp-config`, `--allowedTools mcp__sara`,
  `--no-session-persistence`, `--max-budget-usd 3`). При лимите Opus ход не запускается.
- `RoleMeta.effort` (новое необязательное поле): `--effort` и для обычных ролей, если задано.
- `redact.ts`: `createRedactor(names)`, одно скрытие на весь ход (вход и ответы всех инструментов), метка у
  клиента одна во всех текстах. `redact()` стал обёрткой над ним.
- `apps/core/src/secretary/`: `tools.ts` (16 инструментов: чтение представлениями пульта, действия функциями
  кнопок), `mcp.ts` (MCP по `POST /internal/secretary/mcp`, только с 127.0.0.1 и только с ключом идущего хода),
  `secretary.ts` (очередь ходов, предел в сутки, «печатает…», ответ частями до 4000 знаков), `store.ts`
  (таблица `core.secretary_message`, неделя; память хода: 20 сообщений за трое суток; имена клиентов к скрытию).
- Маршрут слов Бориса (`learning/inbox.ts`): ответ на карточку или вопрос как раньше; без ответа при открытом
  вопросе слова-просьбы (`looksLikeRequest`) идут Секретарю вместе с вопросом, причина без просьбы записывается
  сразу; пока ждётся текст отклика, просьба только по повелительному слову (отклик часто кончается вопросом
  клиенту); всё прочее идёт Секретарю. Ответ Секретаря приходит отдельным сообщением (`onMessage` может вернуть null).
- `pipeline.saveBidText` перенесён из #155 один в один (для `set_bid_text`), `proposeSay` экспортирован.
- Настройка `secretary.turns_per_day` (по умолчанию 60, 0 выключает разговор), видна в пульте в «Уведомлениях».
- Миграция `0016_secretary.sql`. Событие `secretary.answered` (инструменты и исход, без слов).

## Правила безопасности (проверены тестами)

- Отклик за деньги: `offer_bid` присылает кнопку «Откликнуться за N ₽» той же задачи, платит только нажатие.
- Слова клиенту: `offer_client_text` и `offer_draft` присылают кнопку «Отправить»; без открытой карточки отказ.
- Включить траты и письма клиентам нельзя (правило пульта `pultMay`), выключить можно.
- Чужой чат до Секретаря не доходит (прежний фильтр бота); MCP без ключа хода отвечает 404.

## Что осталось

- `/status` без модели и кнопка `web_app` «Открыть» (дизайн M7, раздел 10).
- Свой текст клиенту без открытой карточки (сейчас только из пульта, #155).
- При слиянии с #155: в `pipeline.ts` одинаковый `saveBidText`, в `telegram.ts`, `notifier.ts`, `app.ts` и
  `tests/fakes/telegramApi.ts` правки рядом; конфликты простые.
- На сервере: CLI 2.1.308 знает `--effort`, `--max-budget-usd` и `type: http` в `--mcp-config` (проверено
  `--help`); живой ход на сервере ещё не делали.
