# Дизайн-система: основа

| | |
|---|---|
| Версия | 0.1, 22.10.2026 |
| Статус | основа для M0; компоненты добавляются по мере экранов |
| Технология | Tailwind CSS, компоненты shadcn/ui (на Radix), иконки Lucide |
| Где будет жить | `apps/web/src/design/` (токены и компоненты), витрина компонентов в пульте `/design` |

## 1. Принципы

1. **Вещь выглядит одинаково везде.** Заявка, Клиент, Знание показаны
   одной плашкой в любом разделе, нажатие ведёт в её дом (OOUX, ADR-013).
2. **Решение в 1-2 нажатия.** Главное действие одно и подписано глаголом
   с суммой: «Откликнуться за 210 ₽».
3. **Спокойно.** Акцентный цвет только для главного действия и важного
   состояния.
4. **Телефон первым.** Каждый экран работает на ширине 360 пикселей.

## 2. Токены

С 28.10.2026 пульт берёт стиль лендинга Сары (`apps/site`): тёплый почти
чёрный фон с коралловым свечением сверху, стеклянные карточки с тонкой
рамкой, крупные светлые цифры в коралловом градиенте, кнопки-пилюли.
Тёмная тема это сам лендинг, светлая это его бумажные макеты. Токены
лежат в `apps/web/src/design/tokens.css`, детали в `pult.css`; старые
имена (`--accent`, `--surface`, `--text`, `--muted`) сохранены, и экраны
до M7 берут тот же вид.

| Токен | Тёмная | Светлая | Где |
|---|---|---|---|
| `--bg` | #0c0806 | #f1ece7 | фон |
| `--surface`, `--surface-2` | стекло 3,5 и 6,5% | #ffffff, #faf7f4 | карточки, строки |
| `--text` | #f8f2ed | #1e1a17 | основной текст |
| `--text-2`, `--muted` | 72 и 58% текста | #4a433e, #6c645e | вторичный текст, подписи |
| `--border`, `--border-2` | коралловая линия 10 и 18% | #e3dbd3, #d6ccc2 | рамки |
| `--accent` | #ff6a3d | #f2471f | главное действие, активный раздел |
| `--grad` | #ffc27a → #ff6a3d → #ff4d7d | то же | крупные цифры, полосы, одно слово в заголовке |
| `--grad-btn` | #ff8d5c → #f2471f | то же | главная кнопка, счётчики |
| `--ok`, `--warn`, `--danger` | #5ee6a8, #ffb35c, #ff5f6d | #1f8a57, #a8640f, #c8264f | жива, ждёт, сбой |

- **Шрифты:** Onest для интерфейса, Cormorant Garamond курсивом для одного
  слова в заголовке, Martian Mono для времени, сумм и номеров.
- **Скругления:** 22 пикселя у карточек, 14 у строк, кнопки-пилюли.
- **Движение:** блоки поднимаются из размытия (0,9 с, `cubic-bezier(0.22,
  0.75, 0.2, 1)`) по очереди, подпись кнопки прокручивается при наведении,
  по главной кнопке проходит блик, свет карточки идёт за курсором. При
  «меньше движения» в системе всё стоит на месте.
- **Тема:** как в системе, тёмная или светлая (переключатель в меню).
- **Mini App** берёт цвета из темы Telegram (`themeParams`: фон, текст,
  кнопка), акцент Hance только у главной кнопки.
- Контраст текста не ниже AA (4,5:1), цели нажатия не меньше 44 пикселей,
  видимый фокус для клавиатуры.

## 3. Компоненты

| Компонент | Что показывает | Состояния |
|---|---|---|
| Плашка вещи | тип, имя, ключевой атрибут; ведёт в дом вещи | обычная, выбрана, удалена |
| Карточка заявки | тема, город, балл и «почему», направление, цена отклика, место, сколько ждёт | новая, решена, сгорела |
| Карточка клиента | имя, этап, чей ход, сколько ждёт, аккаунт | Сара ведёт, Борис ведёт, пауза |
| Задача во Входящих | что нужно, срок, к чему относится, кнопки | ждёт, решена |
| Черновик с «почему так» | текст, плашки знаний и образцов, кнопки | черновик, отправлен, отменён |
| Переписка | пузыри клиента, Бориса, Сары, отметка «прочитано» | печатает, доставлено |
| Балл | число 0-100, обоснование по критериям | уверенно, неуверенно |
| Деньги | сумма в ₽, баланс до и после | |
| Переключатель паузы | «Пишет клиентам», «Тратит деньги» | вкл, выкл, ждёт применения |
| Статус-точка | жив, нет связи, сбой | |
| Пустое состояние | что здесь появится и первый шаг | |
| Ошибка с действием | что случилось, кнопка «как исправить» | |
| Шаг мастера | зачем, что сделать, команда с «Скопировать», проверка | не начат, идёт, прошёл, не прошёл |

## 4. Правила текста

- По-русски, простым языком, без длинного тире (проверяется в CI).
- Кнопка это глагол: «Откликнуться», «Отправить», «Беру сам».
- Деньги: `1 250 ₽` (неразрывный пробел), время по Москве: «чт 15:30».
- Ошибка говорит, что случилось и что сделать, без кодов и английских
  слов.
- В пульте иконки, эмодзи только в Telegram.
