## 1. Зачем

Требования спецификации разложены по разделам системы. Карта раскладывает
их по пути Бориса и Сары, чтобы каждая веха давала законченный кусок пути,
а не набор деталей. Первая строка это «ходячий скелет»: самый тонкий
сквозной путь через все главные части системы (термин Алистера Кокберна).

## 4. Что считается готовым срезом

- **R0:** путь A1 → A4 → A5 проходит целиком на Маке с фальшивым Профи.ру
  и настоящим вызовом Claude.
- **R1:** в тени на живой площадке путь A2 → A4 → A5 даёт карточку меньше
  чем за 2 минуты, один настоящий отклик по «да».
- **R2:** в тени Сара пишет черновики ответов, которые сравниваются с
  ответами Бориса.
- **R3:** Борис тренирует Сару; созвоны назначаются; видна цена договора.
- **R4:** выполнены условия выхода из тени, v1 выключена.
- **R5:** два аккаунта, ни одного двойного отклика.
