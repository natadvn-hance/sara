## 1. Профиль: Борис

| | |
|---|---|
| Роль | владелец Hance, единственный пользователь пульта |
| Где работает | телефон весь день (Telegram), компьютер утром и вечером |
| Как пишет | коротко, по-русски, часто без контекста («да», «на общепит») |
| Что ценит | скорость, свой голос в переписке, одно понятное сообщение вместо многих |
| Что раздражает | поток уведомлений, технический язык, когда его спрашивают о том, что можно решить без него, роботный тон Сары |
| Чего боится | траты без его решения, неверное слово клиенту от его имени, потеря клиента из-за молчания |
| Работы (JTBD) | JS-1..JS-9 спецификации |

**Что из этого следует для продукта:**
- Короткое «да» привязано к конкретной задаче, Сара никогда не гадает.
- Уведомления редкие, с кнопками; ночью без звука.
- Любой экран за 10 секунд отвечает «что ждёт меня».
- Тексты интерфейса простым языком, без длинного тире.

## 2. Архетипы клиентов Профи.ру (гипотезы)

Нужны трижды: для тона ответа, для процедур Сары и как персоны тренажёра.
В M4 проверяются на истории чатов: у каждого архетипа должен быть хотя бы
один реальный обезличенный источник (FR-TRAIN-2).

| Архетип | Чего хочет | Чего боится | Как ведёт Сара | Когда зовёт Бориса |
|---|---|---|---|---|
| Срочный малый бизнес | начать на этой неделе | долгих согласований | быстро, конкретно, сразу к созвону | цена, сроки запуска |
| Сравнивающий | собрать 5-10 предложений | переплатить | отличие Hance, кейсы, вопрос о задаче | цена, скидка |
| Неуверенный новичок | понять, что ему вообще нужно | выглядеть некомпетентным | спокойно, вопросами, без терминов | когда задача сложнее брифа |
| Корпоративный | документы, процесс, гарантии | риска для себя | структурно, договор и NDA через Бориса | договор, NDA, реквизиты |
| Ищет дёшево | минимальную цену | что его «разводят» | ценность, без торга | любой торг |
| Заказчик IT | сайт или приложение быстро | что подрядчик пропадёт | быстро, ссылки на 2-3 кейса | смета |

## 3. Карта пути клиента на Профи.ру

Где v1 теряла клиента и что меняет новая Сара.

| Этап | Что делает клиент | Что думает | Где теряли в v1 | Что делает новая Сара | Метрика |
|---|---|---|---|---|---|
| 1. Публикует заказ | описывает задачу, бюджет | «кто-нибудь откликнется?» | | | |
| 2. Первые отклики | читает первые 3-5 откликов | «выберу из первых» | 213 подходящих заявок сгорели в очереди, отклик поздно | карточка Борису меньше 2 минут, отклик за минуту после «да» | G1, G2 |
| 3. Выбор, кому ответить | сравнивает тексты и анкеты | «кто понял мою задачу?» | шаблонный текст | отклик по формату направления, приветствие, кейсы по теме | доля ответов |
| 4. Переписка | задаёт вопросы, торгуется | «можно ли им доверять?» | Сара видела только последнее сообщение, теряла память | досье на каждый ход, ответ в тон, факты только из разума | время ответа, доля без Бориса |
| 5. Договорённость о созвоне | соглашается или тянет | «стоит ли тратить время?» | 0 встреч: правило эскалации срабатывало раньше записи | процедура созвона: 2-3 времени в разные дни, «встреча назначена» Борису | G3 |
| 6. Созвон | говорит с Борисом | | | бриф Борису, напоминания | |
| 7. Решение | договор или отказ | | итоги не записывались | «Прошла ли встреча?», сумма договора | G6 |
