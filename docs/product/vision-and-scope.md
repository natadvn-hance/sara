# Видение и границы: Сара Hance

| | |
|---|---|
| Версия | 1.0, 22.10.2026 |
| Статус | на утверждение Борисом |
| Владелец | Борис Мноян |
| Связано | спецификация `docs/spec/2026-10-22-sara-spec-v1.md`, дорожная карта `docs/product/roadmap.md` |

Зачем этот документ: в одном месте ответить «что мы делаем, зачем, для
кого и что точно не делаем». Спецификация отвечает «как именно», этот
документ отвечает «зачем» и «где граница».

## 1. Видение одной фразой

Сара это ИИ-сотрудник продаж агентства Hance на Профи.ру. Она первой
замечает подходящую заявку, откликается по «да» Бориса за минуту,
разговаривает с клиентом его голосом и доводит до созвона. Борис тратит
время только на решения и на встречи.

## 2. Пресс-релиз из будущего

Метод Amazon «Working Backwards»: до начала работы пишется заметка о
готовом продукте. Если заметка не звучит убедительно, продукт ещё не
придуман. Дата заметки: после переключения с v1 (веха M7).

> **Сара Hance отвечает клиентам Профи.ру как Борис и доводит их до созвона**
>
> Краснодар, февраль 2027. Агентство Hance перевело продажи на Профи.ру
> на новую Сару. Раньше подходящие заявки сгорали в очереди, а разговоры
> с клиентами заканчивались ничем: за 42 дня старая версия отправила 26
> откликов и не назначила ни одной встречи.
>
> Теперь заявка приходит Борису в Telegram меньше чем через 2 минуты
> после публикации, вместе с готовым откликом и кнопкой «Откликнуться за
> 210 ₽». После нажатия отклик уходит за минуту, и Hance оказывается
> среди первых. Дальше Сара ведёт переписку: отвечает в тон клиенту,
> опирается только на то, что знает о Hance, и зовёт Бориса, когда речь
> о цене, договоре или скидке. Когда клиент готов к созвону, Борис
> получает сообщение «встреча назначена» с временем и брифом.
>
> «Утром я вижу три заявки с готовыми откликами, жму "да", а к обеду у
> меня два созвона. Клиенты не замечают, что первые сообщения писал не
> я», говорит Борис Мноян (цель, а не факт).
>
> Сара учится на каждой правке Бориса и на тренировках по 5 минут, где
> она играет клиента. Второй аккаунт с направлением IT работает рядом и
> никогда не спорит с первым за один заказ.

## 3. Вопросы и ответы

**Вопросы Бориса как пользователя**

| Вопрос | Ответ |
|---|---|
| Сколько моего времени нужно? | Первые 2 недели после M3-M4: калибровка направления (20 заявок, около 20 минут), интервью о Hance (около 30 минут), тренировки по 5 минут в день. Потом решения по карточкам, по оценке 10-15 минут в день. |
| Что если Сара ошибётся с клиентом? | На старте всё идёт черновиком, кроме ответов целиком из подтверждённого понимания. Цена, договор, скидки и NDA всегда у тебя. Факт вне разума не уйдёт клиенту. |
| Что будет со старой Сарой? | Работает как сейчас до переключения на M7, потом месяц стоит выключенной для отката. |
| Где я всё вижу? | Telegram (новый бот), Mini App в нём, веб-пульт на компьютере. Одни и те же данные везде. |
| Как понять, что Сара готова? | По условиям выхода из тени (спецификация, раздел 12) и экзамену. Решение о переключении твоё. |

**Внутренние вопросы**

| Вопрос | Ответ |
|---|---|
| Почему не допилить v1? | Аудит: 12 критичных находок, и половина из них в устройстве (сессия чата как мозг, нет журнала, память теряется). Заплатки это уже пробовали. |
| Почему без API Claude? | Решение Бориса: только подписка через `claude -p` (ADR-001). Шлюз спрятан за интерфейсом, переход на API возможен без переделки. |
| Сколько стоит содержать? | Сервер 1000-2500 ₽ в месяц плюс IP на аккаунт, отдельная подписка Claude, отклики по решению Бориса. Раздел 5. |
| Что может всё сломать? | Блокировка аккаунта, смена сайта Профи.ру, лимит подписки, закон о данных. Меры: модель угроз и реестр рисков. |
| Что считаем провалом, даже если «работает»? | Анти-цели: выдуманные факты, траты без решения, поток уведомлений, два аккаунта на одном заказе, роботный тон, ответ поверх ответа Бориса, потеря памяти. |

## 4. Цели и главная метрика

**Главная метрика (North Star):** число созвонов с подходящими клиентами
в неделю. Она растёт, только если работают все звенья: скорость, отклик,
разговор, процедура созвона.

**Входные метрики** (цели G1-G7 спецификации):

| Звено | Метрика | Цель |
|---|---|---|
| Скорость | заявка у Бориса | меньше 2 минут у 90% (G1) |
| Решение | от «да» до отклика | меньше 60 секунд (G2) |
| Разговор | ответил → созвон | от 25% (G3) |
| Голос | слепой тест | Борис угадывает не лучше 50% (G4) |
| Нагрузка | ответы без Бориса | 60% через 2 месяца после M5 (G5) |
| Деньги | цена ответа, созвона, договора | считается каждый день (G6) |
| Ошибки | дубли, выдуманные факты, потери | 0 (G7) |

## 5. Экономика воронки

Вместо Lean Canvas: Сара не продаётся, у неё один заказчик (Hance). Важна
только экономика одной заявки.

**Формула:** цена договора = цена отклика / (доля ответов × доля
созвонов × доля договоров).

| | v1, факт с 09.09 по 21.10 | Цель новой Сары |
|---|---|---|
| Средняя цена отклика | 126 ₽ (3277 ₽ / 26) | та же или ниже за счёт отбора |
| Доля ответов клиентов | 70% (16 из 23) | 70% и выше за счёт скорости |
| Цена ответа | 205 ₽ | около 180 ₽ |
| Доля «ответил → созвон» | 0% | 25% |
| Цена созвона | нет | около 720 ₽ |
| Доля «созвон → договор» | неизвестно | меряем с M6 |
| Цена договора | нет | при 20% около 3600 ₽ |

**Постоянные расходы:** сервер до 2500 ₽ в месяц плюс IP на аккаунт и подписка Claude.
Окупаемость считается по среднему чеку Hance, его нужно назвать (открытый
вопрос В-1 в разделе 10).

## 6. Границы

### 6.1 Входит в первую версию (M0-M8)

- Один или несколько аккаунтов Профи.ру, у каждого направление со своей
  системой оценки, форматом отклика и кейсами; маршрутизатор.
- Заявка: замечена, оценена, черновик отклика, карточка Борису, отклик по
  «да».
- Разговор с клиентом голосом Бориса по циклу из 8 шагов, самостоятельность
  по темам, процедура созвона, «встреча назначена» в Telegram.
- Разум Сары (знание, понимание, речь, суждение, память) с версиями.
- Тренажёр с пятью режимами, уроки из правок, ночной учитель, экзамен.
- Пульт: веб-приложение, Mini App, бот. Мастер первого запуска.
- Аналитика воронки и денег, журнал «почему так».
- Эксплуатация: один сервер за рубежом, бэкапы, тревоги, инструкции на случай сбоя,
  переключение с v1.

### 6.2 Не входит, и почему

| Что | Почему |
|---|---|
| Лора, Ultimate Hance | решение Бориса 22.10: только Сара |
| Календарь, ссылки на видеовстречи | решение Бориса 22.10: встречу отмечает он сам |
| Звонки голосом | не нужно для цели, высокий риск |
| Другие площадки (Авито, FL.ru) | сначала доказать на Профи.ру |
| Продажа Сары как продукта | не цель |
| Дообучение весов модели | недоступно и не нужно (ADR-008) |
| Автоотклик без правила | траты только по «да» или правилу направления |
| Несколько пользователей пульта | пользователь один, Борис |
| API Claude по ключу | решение Бориса 21.10 (ADR-001) |

### 6.3 Кандидаты на потом

Ценность заявки в рублях после 100 итогов; второй пользователь
(менеджер); календарь; другие площадки.

## 7. Ограничения

- Модель только по подписке; лимит общий на все роли.
- У Профи.ру нет API для специалистов; площадка режет зарубежные IP.
- Сервер за рубежом, как у v1 (решение Бориса); Профи.ру иногда не пускает зарубежные IP.
- Закон о персональных данных (152-ФЗ).
- Бюджет сервера до 2500 ₽ в месяц плюс IP на аккаунт.
- Разработку ведут сессии Claude Code; решения принимает один человек.

## 8. Предположения, которые проверяем

Каждое предположение может оказаться ложным. Проверяем как можно раньше.

| № | Предположение | Как проверим | Когда | Если ложно |
|---|---|---|---|---|
| A1 | `claude -p` с токеном `setup-token` стабильно работает в контейнере на сервере | сквозной путь M0, затем сутки вызовов | M0 | ключ API как запасной путь (ADR-001) |
| A2 | события `window.__RTP` приходят в кабинет специалиста | калибровка | M1, первые 2 дня | чтение данных из ответов сайта и обновление ленты |
| A3 | вход нового сервера не выбивает сессию v1 (две сессии одного аккаунта) | наблюдение 48 часов | M1 | новая Сара только наблюдает по расписанию до M7 |
| A8 | Профи.ру пускает зарубежный сервер достаточно стабильно (v1: одна блокировка на 48 минут за 42 дня) | доля времени без связи | M1-M2 | российский прокси на выход браузера (решает Борис) |
| A4 | скорость отклика повышает долю ответов | когорты «быстро» и «медленно» | M2-M3 | упор на текст и отбор |
| A5 | голос Бориса воспроизводим по истории Профи.ру | слепой тест | M4-M5 | больше тренажёра и интервью |
| A6 | 25% ответивших соглашаются на созвон в переписке | воронка | M6 | пересмотр процедуры созвона |
| A7 | правила Профи.ру разрешают второй аккаунт | вопрос в поддержку | до M8 | второе направление на том же аккаунте |
