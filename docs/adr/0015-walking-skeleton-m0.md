# ADR-015. M0 как ходячий скелет

- Статус: предложено
- Дата: 22.10.2026

## Контекст
В спецификации M0 это фундамент без сквозного пути. Самые рискованные
предположения (A1: `claude -p` в контейнере; устойчивые процессы)
проверялись бы только в M2.

## Решение
M0 заканчивается сквозным путём: фальшивая заявка → журнал → настоящий
вызов Сортировщика → карточка в бот → «да» → исходящая очередь →
фальшивый отклик → журнал. Термин Алистера Кокберна: самый тонкий путь
через все главные части, который потом наращивается, а не выбрасывается.

## Последствия
M0 немного больше (бот и шлюз в минимальном виде), зато главные риски
снимаются в первую неделю.
