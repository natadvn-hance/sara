# ADR-006. Postgres, журнал событий, устойчивые процессы

- Статус: принято; DBOS проверяется в M0 (ST-M0-05)
- Дата: 22.10.2026

## Контекст
В v1 база SQLite, нет истории, ожидания и напоминания терялись при
перезапуске.

## Решение
Postgres 16 с pgvector. Журнал событий только на добавление, источник
правды. Устойчивые процессы (ожидания, напоминания, ночные задачи) на
DBOS Transact в той же базе.

## Рассмотренные варианты
- SQLite: одна запись за раз.
- Temporal: отдельный тяжёлый сервер.
- pg-boss: запасной вариант, если DBOS не пройдёт проверку.

## Последствия
Перезапуск любого процесса не теряет ожиданий (NFR-REL-3).
