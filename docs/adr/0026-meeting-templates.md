# ADR-026. Шаблоны процедуры созвона идут клиенту без черновика и без номеров фактов

- Статус: предложено
- Дата: 25.10.2026
- Решил: разработка (Борис видит и может оспорить; в дизайне M6 это решение 15)

## Контекст
Процедура созвона (дизайн M6, раздел 5.2) отвечает клиенту короткими
текстами: предложить 2-3 времени, подтвердить выбранное, перенести,
принять отмену. Время в них берётся из свободного времени Бориса и
записанных встреч, поэтому тексты собирает код по готовым шаблонам
(раздел 5.4), а не модель.

Правила разговора M4 построены для ответов модели: на старте каждая тема
идёт черновиком Борису (FR-AUTO-2, `conv.autonomy`), а ответ без номеров
записей разума не отправляется (FR-CONV-3). Если применить их к шаблонам,
каждое предложение времени и каждое подтверждение станет черновиком, и
клиент будет ждать Бориса ради сообщения, в котором нечего решать.

## Решение
Тексты процедуры созвона (`ProcedureResult` с `topic: 'call'`) проверяются
набором для шаблонов (длинное тире, приветствие нового дня, потолок 600
знаков) и идут клиенту по своей настройке `meet.autonomy`: `self`
(отправлять самой, по умолчанию) или `draft` (черновиком Борису). Номера
фактов разума у них не требуются: текст собран кодом из настроек. Тень,
пауза «Пишет клиентам», ночь, владелец клиента и перечитывание чата перед
отправкой действуют, как для любого ответа. Список шаблонов меняется только
с согласия Бориса.

## Рассмотренные варианты
- Шаблоны по уровню темы `call` из `conv.autonomy`: на старте всё черновик,
  процедура не работает, пока Борис не поднимет тему, а 📅 «назначена»
  приходит раньше, чем клиент что-то получил.
- Тексты процедуры пишет Собеседник с номерами фактов: время и даты
  придумывает модель, при лимите Claude процедура стоит; так ошибалась v1.

## Последствия
- M4 при подключении M6 различает текст процедуры и ответ Собеседника
  (раздел 7.3 дизайна M6).
- Экзамен M4 получает сценарии процедуры, чтобы правка шаблонов или роли
  `scheduler` проходила сторож выкладки.
- Готовый текст v1 на просьбу созвона, который M4 шлёт при лимите Claude,
  остаётся по правилам M4.
