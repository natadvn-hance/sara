# ADR-025. Сара сама записывает в разум после «да» Бориса

- Статус: предложено (решила разработка 25.10.2026 ночью по заранее данному разрешению Бориса; Борис может оспорить)
- Дата: 25.10.2026
- Решил: разработка (Борис видит и может оспорить)
- Связано: FR-MIND-3, FR-TRAIN-6, FR-TRAIN-9, ADR-007, ADR-008, дизайн M5 `docs/superpowers/specs/2026-10-25-m5-trainer-design.md` (раздел 5.3), дизайн M4 (раздел 5.2)

## Контекст
Разум Сары это git-репозиторий файлов `sara-mind` (ADR-007). M4 решил,
что ядро разум только читает: всё, что Сара предлагает, копится строками
`core.mind_proposal`, а в репозиторий их переносит разработка командами
`mind:proposals` и `mind:accept` после «да» Бориса.

Для M5 этого мало. Уроки приходят каждый день: из правок Бориса, из
тренажёра, от ночного учителя. Приёмка вехи: «уроки попали в разум».
FR-MIND-3: изменения только после «да» Бориса, откат одной кнопкой. Если
каждое «да» ждёт, пока человек из разработки откроет пул-реквест в
`sara-mind`, урок вступает в силу через дни, а откат кнопкой невозможен.

## Решение
Ядро пишет в свой клон `sara-mind` на сервере (`SARA_MIND_DIR`), и только
в одном месте: писатель разума `apps/core/src/mind/writer.ts`.
1. Писатель берёт только предложения, на которые Борис сказал «да»
   (урок в состоянии `yes` или карточка «Да, все»), собирает файл из
   полей сам (модель текст файла не пишет), проверяет его (схема, номер,
   источники без `sim:` и со словами Бориса, без данных клиента, числа
   знания только из слов Бориса) и делает один коммит от имени Сары с
   номерами уроков.
2. Индекс перестраивается сразу; версия разума это `HEAD`.
3. Откат это `git revert` нужного коммита одной кнопкой.
4. Ночью клон перебазируется на `origin/main` (правки разработки
   приходят пул-реквестами в `sara-mind`) и отправляется в GitHub
   отдельным ключом с правом записи только в `sara-mind`. Конфликт не
   ломает ничего: локальные коммиты остаются, Борису одно сообщение в
   день.

## Рассмотренные варианты
- Оставить как в M4 (разработка переносит предложения): «да» Бориса
  срабатывает через дни и только при участии человека; откат кнопкой
  невозможен.
- Хранить разум в базе, а в git выгружать копию: теряется главное ADR-007
  (история и откат в git бесплатны, Claude Code работает с файлами), два
  источника правды.
- Писать прямо в GitHub через API без клона: ядро зависит от сети на
  каждое «да»; индекс строится по клону всё равно.

## Последствия
- В образе ядра нужны `git` и `openssh-client`; на сервере ключ
  развёртывания с правом записи только в `sara-mind` (файл с правами 600).
- Выкладка больше не делает `git pull` в клон разума; вместо этого
  `pnpm mind sync` в контейнере ядра (runbook «Разум»).
- Разум в git дважды: на сервере и в GitHub (спецификация, раздел 10);
  до первой ночной отправки свежие коммиты есть только на сервере.
- Команды M4 `mind:proposals` и `mind:accept` остаются для разработки на
  Маке; папка `proposals/` в репозитории нужна только им.
- Отравление разума (модель угроз T14) по-прежнему закрыто «да» Бориса;
  проверки писателя добавляют защиту от синтетики, данных клиента и
  выдуманных чисел.
