# ADR-018. Поток поставки: короткие ветки, Conventional Commits, release-please

- Статус: предложено
- Дата: 22.10.2026

## Решение
- Ветка на историю, живёт до дня, слияние в `main` через пул-реквест с
  зелёным CI и проверкой кода.
- Сообщения коммитов по Conventional Commits (`feat:`, `fix:`, `docs:`).
- release-please готовит выпуск: номер версии и `CHANGELOG.md`.
- После выпуска Борису уходит «Что нового» простым языком.

## Последствия
История изменений и версии собираются сами, без ручной работы.
