# ADR-017. Два фальшивых Профи.ру и записанные образцы

- Статус: предложено
- Дата: 22.10.2026

## Решение
1. Фальшивый Профи-MCP с контрактом C2: для ядра, разработки и CI.
2. Фальшивый сайт из записанных страниц и событий: для тестов службы Профи-MCP
   (разбор и действия Playwright).
3. Образцы из калибровки M1 хранятся обезличенными в `tests/fixtures`.

## Последствия
Ни один тест не ходит на живой Профи.ру. Живая площадка только в тени.
