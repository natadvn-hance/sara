# ADR-007. Разум как git-репозиторий файлов плюс индекс

- Статус: принято
- Дата: 22.10.2026

## Контекст
Разум (знание, понимание, речь, суждение) меняется каждый день после «да»
Бориса и должен откатываться независимо от кода.

## Решение
Отдельный приватный репозиторий `sara-mind` с Markdown-файлами (контракт
C6). Подтверждение Бориса это коммит. Индекс в Postgres (полнотекстовый
поиск по-русски и векторы) обновляется после коммита.

## Рассмотренные варианты
- Только таблицы: хуже история и откат.
- Отдельная графовая база: избыточно.

## Последствия
Каждый ответ клиенту хранит версию разума, на которой написан.
