# ADR-014. Контракты в коде на zod

- Статус: предложено
- Дата: 22.10.2026

## Контекст
Части системы пишут разные сессии. Им нужен один источник правды о
формах данных. Ручной OpenAPI расходится с кодом.

## Решение
Схемы всех контрактов (C1-C8) пишутся на zod в
`packages/shared/contracts`. OpenAPI пульта и JSON Schema ролей и MCP
генерируются в CI. Ломающее изменение только новой версией контракта.

## Рассмотренные варианты
- OpenAPI руками сначала (API-First в чистом виде): двойная работа на
  одного разработчика.
- Типы TypeScript без схем: нет проверки во время работы.

## Последствия
Тесты контрактов на образцах обязательны (DoD).
