# ADR-019. Узел доставляет события, а не копирует базу

- Статус: принято с изменением ADR-021: служба Профи-MCP на том же сервере, её очередь в схеме `node` общей базы
- Дата: 22.10.2026

## Контекст
Данные клиентов сначала пишутся в России (ADR-005), а работает с ними
ядро за рубежом.

## Решение
Узел пишет событие в свою базу, затем доставляет его в ядро через свою
исходящую очередь (контракт C8). Ядро принимает событие с тем же номером
один раз.

## Рассмотренные варианты
- Логическая репликация Postgres: копирует всё подряд, включая сырые
  данные, и связывает схемы двух баз.

## Последствия
В ядро уходит только нужное; при обрыве связи узел досылает события.
