# ADR-004. Два узла и отдельный IP на аккаунт

- Статус: заменено ADR-021 (22.10.2026: Борис решил, что сервер будет за рубежом, как у v1)
- Дата: 22.10.2026

## Контекст
Claude официально недоступен из России. Профи.ру режет зарубежные IP
(08.10.2026 защита 48 минут не пускала сервер v1 в Болгарии).

## Решение
Узел ядра за рубежом, узел Профи.ру в России. Изоляция аккаунта это свой
профиль браузера и свой IP на узле, а не свой сервер. Связь WireGuard.

## Рассмотренные варианты
- Один сервер: конфликт стран.
- Сервер на аккаунт: дороже без пользы.
- Платные прокси: дорого и ненадёжно.

## Последствия
Около 2000-3500 ₽ в месяц. Узел России нужен с M1, ядро с M2.
