# ADR-022. Данные клиентов хранятся на сервере за рубежом

- Статус: принято
- Дата: 22.10.2026
- Решил: Борис
- Заменяет: ADR-005

## Контекст
152-ФЗ, ст. 18 ч. 5 требует, чтобы данные граждан России при сборе
сначала записывались в базу в России. Штраф 1-6 млн ₽, в том числе для
ИП, повторно 6-18 млн ₽. Борису это объяснено 22.10; он решил держать
сервер за рубежом, как у v1 (ADR-021).

## Решение
Данные клиентов (имя, текст заказа, переписка, контакт для встречи)
хранятся на сервере за рубежом. Чтобы уменьшить риск:
- данных минимум: только то, что нужно для работы;
- перед вызовом Claude данные обезличиваются (ADR-016);
- сроки хранения и удаление по просьбе клиента (словарь данных, раздел 4);
- консультация юриста до M1 (вопросы в модели угроз, раздел 5).

Сырые данные площадки лежат отдельно, в схеме `node`. Если юрист скажет,
что без первой записи в России нельзя, эту схему можно перенести в
управляемую базу в России (без своего сервера) без переделки ядра.

## Рассмотренные варианты
- Первая запись в России на своём узле (ADR-005): Борис против сервера в
  России.
- Управляемая база в России только для первой записи: оставлено запасным
  путём по итогам юриста.

## Последствия
Риск по 152-ФЗ принят Борисом и записан в реестре рисков спецификации.

**Решение Бориса 24.10.2026 (ворота В3 плана M1):** идём без консультации
юриста, риск по 152-ФЗ Борис принимает. Меры из раздела «Решение»
остаются в силе: минимум данных, обезличивание перед Claude, сроки
хранения, удаление по просьбе клиента. Копии базы зашифрованы и лежат
в России (Санкт-Петербург).
