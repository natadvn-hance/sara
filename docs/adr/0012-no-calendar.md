# ADR-012. Без календаря в первой версии

- Статус: принято
- Дата: 22.10.2026
- Решил: Борис

## Решение
Сара назначает созвон из свободного времени в настройках и пишет Борису
«встреча назначена». Итог отмечает Борис. Встречи идут в Яндекс
Телемосте, ссылку Сара не создаёт.

## Последствия
Нужна таблица свободного времени и проверка пересечений встреч.

## Уточнение 25.10.2026 (дизайн M6)
Свободное время хранится не отдельной таблицей, а настройкой
`meet.availability` с историей изменений (`setting_history`): смысл
решения тот же, кода меньше. Пересечения встреч проверяет код под одной
блокировкой (дизайн M6, раздел 5.2).
