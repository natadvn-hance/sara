# ADR-023. Вход на Профи.ру через живой экран вкладки

- Статус: принято
- Дата: 23.10.2026
- Связано: FR-SET-4, FR-ACC-6, ADR-003, ADR-021

## Контекст
В v1 Борис входил на Профи.ру на Маке командой `npm run login`, затем
сессия переносилась на сервер. Нужен Мак и терминал; с телефона нельзя.
Новая Сара держит браузер аккаунта на сервере (ADR-021), второй браузер
с той же сессией запрещён (ADR-003).

## Решение
Борис входит прямо во вкладку сервера. Служба Профи-MCP отдаёт кадры
вкладки через CDP screencast (JPEG, качество 60) по WebSocket во
внутренней сети; ядро пропускает их в пульт только при входе в пульт;
нажатия и набор текста идут обратно. Пароль и код из СМС проходят как
нажатия клавиш и нигде не сохраняются и не пишутся в журналы.

## Рассмотренные варианты
- noVNC с отдельным X-сервером: тяжелее, ещё одна служба и порт.
- Вход на Маке с переносом cookie (как v1): нужен Мак, с телефона нельзя.

## Последствия
Новые библиотеки: `ws` в службе и `@fastify/websocket` в ядре (строки в
техрадаре). Экран работает только для аккаунта, чей браузер открыт.
