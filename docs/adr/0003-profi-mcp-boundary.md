# ADR-003. Профи-MCP как единственная граница с площадкой

- Статус: принято
- Дата: 22.10.2026

## Контекст
В v1 доступ к браузеру шёл из разных мест. 29.09.2026 второй браузер с
той же сессией убил вход.

## Решение
Только служба Профи-MCP владеет браузерами аккаунтов. Ядро работает с
площадкой через инструменты и уведомления MCP (контракт C2). Второй
браузер с сессией аккаунта запрещён.

## Рассмотренные варианты
- Браузер внутри ядра: смешивает работу с площадкой и логику Сары, нельзя
  перезапускать и проверять отдельно.

## Последствия
Есть фальшивый Профи-MCP с тем же контрактом для тестов и разработки.
