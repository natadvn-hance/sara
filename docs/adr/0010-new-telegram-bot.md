# ADR-010. Новый бот Telegram

- Статус: принято (Борис, 22.10.2026); заменяет мысль из дизайна v3,
  раздел 26, о прежнем боте
- Дата: 22.10.2026

## Контекст
Два приложения не могут читать одного бота одновременно, а v1 работает
до переключения.

## Решение
Новый бот для работы и отдельный бот для разработки на Маке. Создаются
в мастере запуска за 2 минуты.

## Последствия
После переключения старый бот отключается вместе с v1.
