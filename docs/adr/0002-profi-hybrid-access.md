# ADR-002. Профи.ру гибридно: события читать, интерфейсом действовать

- Статус: принято
- Дата: 22.10.2026
- Решил: Борис (принцип), разработка (устройство)

## Контекст
У Профи.ру нет API для специалистов. Площадка сама решает, кому первым
показать заказ, и учитывает долю договорённостей. Кабинет специалиста
получает события через `window.__RTP` с `online.profi.ru`.

## Решение
Читаем тремя способами по порядку надёжности: события `__RTP`, данные из
ответов сайта, разметка страницы как запасной путь. Действуем только
через интерфейс страницы: клики и набор текста с человеческим темпом,
после каждого действия проверка экраном.

## Рассмотренные варианты
- Только экран (как v1): медленно и ломается от вёрстки.
- Прямые запросы к сайту: быстро, но риск блокировки аккаунта.
- Закрытый API мобильного приложения: защита и риск.

## Последствия
Нужна калибровка в M1: какие события реально приходят специалисту. Тесты
строятся на записанных образцах.
