# ADR-009. Направления аккаунтов и маршрутизатор

- Статус: принято
- Дата: 22.10.2026
- Решил: Борис

## Контекст
Второй аккаунт другого характера не должен бороться с первым за один
заказ.

## Решение
У аккаунта направление со своей системой оценки, форматом отклика,
кейсами и режимом скорости. Маршрутизатор отдаёт заказ одному
направлению; если подходят оба, одна карточка с выбором.

## Последствия
Два отклика на один заказ невозможны: проверка в коде (уникальность по
номеру заказа в `outbox`) и в тесте.
