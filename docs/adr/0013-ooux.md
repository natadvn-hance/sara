# ADR-013. Интерфейс по карте сущностей (OOUX)

- Статус: принято
- Дата: 22.10.2026

## Решение
Сначала карта вещей (объекты, связи, действия, атрибуты), потом экраны.
У вещи один дом и одинаковая плашка везде (дизайн v3, раздел 16).

## Последствия
API пульта устроен по тем же вещам (контракт C4).
