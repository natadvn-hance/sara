# ADR-008. Обучение без дообучения модели

- Статус: принято
- Дата: 22.10.2026

## Контекст
Дообучение Claude клиентам недоступно; своя модель дороже и слабее.

## Решение
Сара учится через разум, образцы речи Бориса, уроки из правок, тренажёр,
ночного учителя и экзамен.

## Последствия
Качество меряется экзаменом и слепым тестом, а не потерями обучения.
