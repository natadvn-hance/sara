# ADR-011. Монорепозиторий на TypeScript

- Статус: принято
- Дата: 22.10.2026

## Решение
Один репозиторий `sara`: `apps/core`, `apps/web`, `apps/profi-node`,
`packages/shared`, `roles/`, `infra/`, `docs/`, `tests/`. Один язык,
общие типы и контракты. Пульт и Mini App из одного кода на React.

## Рассмотренные варианты
- Разные языки для частей: дороже сопровождать.
- Разные репозитории для частей: контракты расходятся.
