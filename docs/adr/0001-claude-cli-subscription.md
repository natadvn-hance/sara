# ADR-001. Модель через Claude Code CLI по подписке

- Статус: принято
- Дата: 21.10.2026
- Решил: Борис

## Контекст
Сара вызывает модель десятки раз в день. Борис не хочет платить за
токены API. Официальная справка Anthropic: `claude -p` и Agent SDK
расходуют лимиты подписки.

## Решение
Все роли вызываются через `claude -p` с закреплённой версией CLI, токеном
`claude setup-token` (`CLAUDE_CODE_OAUTH_TOKEN`), без сохранения сессий,
без инструментов, с ответом по JSON Schema. Шлюз модели спрятан за
интерфейсом.

## Рассмотренные варианты
- API по ключу: платно за каждый вызов.
- Agent SDK в коде: тот же лимит, но больше кода; можно перейти позже.

## Последствия
Лимит общий на все роли, поэтому нужен шлюз с приоритетами и ночное окно
для учёбы. Флаг `--bare` не используется (требует ключ API). Если
Anthropic изменит правила, шлюз переключается на API без изменений в
остальном коде.
