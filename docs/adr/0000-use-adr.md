# ADR-000. Записывать архитектурные решения в формате MADR

- Статус: принято
- Дата: 22.10.2026

## Контекст
Систему строят разные сессии Claude Code. Каждая начинает без памяти о
прошлых разговорах. Если причина решения не записана, следующая сессия
переделает решение или нарушит его.

## Решение
Каждое решение, которое трудно отменить или которое влияет на несколько
частей системы, записывается файлом `docs/adr/NNNN-коротко.md` по шаблону
MADR (Markdown Architectural Decision Records): контекст, решение,
рассмотренные варианты, последствия. Файл не переписывается: если решение
меняется, пишется новый ADR со ссылкой «заменяет ADR-NNN», а у старого
меняется статус.

## Рассмотренные варианты
- Таблица решений в спецификации: удобно читать, но теряются контекст и
  отвергнутые варианты.
- Решения только в описаниях пул-реквестов: трудно найти.

## Последствия
Таблица ADR в спецификации (раздел 18) остаётся оглавлением, а полный
текст живёт здесь. Шаблон: `docs/adr/template.md`.
