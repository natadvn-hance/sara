# ADR-016. Обезличивание перед вызовом модели

- Статус: предложено
- Дата: 22.10.2026

## Контекст
Вызов Claude передаёт текст в США. Это трансграничная передача данных
клиентов в страну без адекватной защиты по 152-ФЗ.

## Решение
Перед вызовом шлюз заменяет имена, телефоны, почту, ссылки на профили и
адреса метками (`[Имя]`, `[Телефон 1]`), а в ответе возвращает настоящие
значения. В вызов идёт минимум досье, нужный роли. В `model_call`
пишется, было ли обезличивание.

## Рассмотренные варианты
- Ничего не менять: юридический риск.
- Не вызывать модель на данных клиентов: продукта нет.

## Последствия
Модель не видит имени клиента и обращается по метке; шлюз подставляет
имя. Тест: ни одного телефона или почты в тексте вызова.
