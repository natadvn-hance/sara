# ADR-020. Drizzle и миграции «расширить, потом сузить»

- Статус: предложено
- Дата: 22.10.2026

## Решение
Схема базы и миграции на Drizzle ORM и drizzle-kit. Каждая миграция
совместима с прошлой версией кода: сначала добавить новое, перенести
данные, переключить код, и только в следующем выпуске удалить старое.

## Последствия
Откат версии кода не требует отката базы.
