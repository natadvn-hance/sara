# ADR-005. Первая запись данных клиентов в России

- Статус: заменено ADR-022 (22.10.2026: Борис решил хранить данные на сервере за рубежом)
- Дата: 22.10.2026

## Контекст
152-ФЗ, ст. 18 ч. 5: данные граждан России при сборе сначала
записываются в базу в России. Штраф 1-6 млн ₽, в том числе для ИП.

## Решение
Узел Профи.ру первым получает данные с площадки и пишет их в свою базу
`postgres-ru`, затем доставляет события в ядро (ADR-019). Уведомления в
Роскомнадзор и политика обработки по итогам консультации юриста.

## Рассмотренные варианты
- Всё за рубежом: риск штрафа.
- Всё в России: Claude недоступен.

## Последствия
Сырые данные на узле живут 30 дней. Вызов Claude это тоже передача за
рубеж, поэтому данные перед моделью обезличиваются (ADR-016).
