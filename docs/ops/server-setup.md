# Сервер для новой Сары: что купить и что прислать

| | |
|---|---|
| Версия | 1.0, 23.10.2026 |
| Для кого | Борис (покупка), Сара (настройка) |
| Связано | ADR-021, `docs/architecture/deployment.md`, план M1, задача 13 |

## 1. Что купить

Отдельный сервер, не тот, где работает старая Сара: если новая Сара
будет мешать на одном сервере, пострадает старая, которая приносит
заявки.

| Что | Сколько |
|---|---|
| Где | за рубежом, где официально работает Claude; можно у того же провайдера, что у старой Сары |
| Процессор | 2-4 ядра |
| Память | 4-8 ГБ (браузер аккаунта и база) |
| Диск | 60 ГБ |
| Система | Ubuntu 24.04 |
| IP-адреса | основной плюс **один дополнительный IPv4** для аккаунта Профи.ру |
| Цена-ориентир | 1000-2500 ₽ в месяц плюс 150-250 ₽ за дополнительный IP |

Дополнительный IP обычно заказывается в панели провайдера кнопкой
«Добавить IP» или письмом в поддержку.

Ещё нужно: хранилище резервных копий S3 у **другого** провайдера (если
сервер сгорит, копии уцелеют), около 50 ГБ, и доменное имя или поддомен
для пульта (например, `sara.hance.ru`), который смотрит на основной IP.

## 2. Что прислать Саре

1. Основной IP сервера и пароль root (Сара сразу заменит вход по паролю
   входом по ключу и пароль больше не нужен).
2. Дополнительный IP для аккаунта.
3. Домен или поддомен для пульта.
4. Доступ к хранилищу S3: адрес, ключ доступа, секретный ключ, имя
   хранилища.

Пароли не пиши в Telegram-чат с ботом: передай их через терминал на Маке
(Сара подскажет команду) или в зашифрованной заметке.

## 3. Что сделает Сара (для справки)

1. Пользователь `sara` без прав root, вход только по ключу, root по SSH
   выключен.
2. Firewall: открыты только 22 (SSH) и 443 (пульт).
3. Docker, второй IP на сетевом интерфейсе, проверка, что SOCKS аккаунта
   выходит в сеть именно с него.
4. Секреты в `/opt/sara/.env.sops`, зашифрованные ключом сервера (sops,
   age).
5. Выкладка `scripts/deploy.sh`, мастер запуска на `https://<домен>`,
   первый бэкап и пробное восстановление.
