# Сара Hance: правила для сессий разработки

Ты разрабатываешь новую Сару: ИИ-сотрудника продаж агентства Hance на
Профи.ру. Владелец продукта Борис Мноян. Ты не Сара в работе, а её
разработчик.

## С чего начать любую сессию

1. `docs/README.md`: карта документов.
2. Последний документ передачи дел в `docs/handoff/` (самый новый файл).
3. Спецификация `docs/spec/` и записи решений `docs/adr/`.
4. Бэклог `docs/product/backlog.md` (после создания репозитория: GitHub
   Project) и правила готовности `docs/quality/definition-of-ready-and-done.md`.

## Как работаем

- Новая работа: вопросы и дизайн (superpowers:brainstorming), план
  (superpowers:writing-plans), тесты первыми
  (superpowers:test-driven-development), проверка кода отдельной сессией,
  проверка перед словом «готово» (superpowers:verification-before-completion).
- История берётся в работу только по DoR и сдаётся только по DoD.
- В названии теста номер требования: `it('FR-LEAD-4: ...')`.
- Коммиты по Conventional Commits на английском (`feat:`, `fix:`, `docs:`).
- Решение, которое трудно отменить, записывается ADR (`docs/adr/template.md`).
- После каждого блока работы обновляется документ передачи дел.
- Крупный документ для Бориса публикуется страницей с комментариями, ему
  даётся ссылка.

## Борис

- Пиши ему по-русски, простым языком, одним понятным сообщением.
- Никогда не используй длинное тире: ни Борису, ни в текстах для
  клиентов, ни в интерфейсе. Вместо него запятая, точка, двоеточие или
  короткий дефис. CI это проверяет.
- Коммит в общий репозиторий, создание репозиториев, покупка серверов,
  изменения во внешних сервисах, траты: только после его явного «да» на
  это конкретное действие.

## Нельзя

- Трогать старую Сару: папку `~/(SaraAI)Профи.Ру — бот ` (с пробелом в
  конце) и сервер v1. Только чтение и только когда это нужно для задачи.
- Открывать Профи.ру с сессией любого аккаунта во втором браузере. С
  площадкой работает только служба Профи-MCP (ADR-003). 29.09.2026 второй
  браузер убил сессию v1.
- Ходить в тестах на живой Профи.ру. Для тестов есть фальшивый Профи.ру и
  записанные образцы (ADR-017).
- Класть в репозиторий секреты и данные клиентов. Образцы для тестов
  только обезличенные. Секреты только в sops-файлах.
- Вызывать модель Claude в CI: токен подписки остаётся на сервере.
- Давать ролям Сары инструменты и доступ к файлам. Модель предлагает, код
  решает (деньги, отправка, паузы).

## Устройство коротко

- `apps/core`: ядро и бот (TypeScript, Fastify, Postgres, DBOS, grammY).
- `apps/web`: пульт и Mini App (React, Vite).
- `apps/profi-node`: служба Профи-MCP с браузерами аккаунтов (Playwright, MCP SDK).
- Всё работает на одном сервере за рубежом, как v1 (ADR-021). Сервера в России нет.
- `packages/shared`: контракты на zod (C1-C8, `docs/architecture/contracts.md`).
- `roles/`: инструкции ролей Claude и схемы ответов.
- `infra/`: Docker Compose, выкладка, бэкапы.
- `tests/`: фальшивый Профи.ру, образцы, экзамен.
- Разум Сары живёт в отдельном репозитории `sara-mind`.
