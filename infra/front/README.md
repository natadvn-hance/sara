# Сервер-вход (213.155.28.126)

Решение Бориса 23.10.2026: адрес основного сервера 94.177.51.236 недоступен
из России, поэтому всё, что идёт в Россию и из России, проходит через
сервер-вход в той же VDSka (Нидерланды), чей адрес из России работает.

| Что | Как |
|---|---|
| Туннель | WireGuard `wg0`: основной 10.77.0.1, вход 10.77.0.2, UDP 51820 только с основного |
| Пульт | Caddy на входе: `https://213-155-28-126.sslip.io` → туннель → Caddy основного на `10.77.0.1:8080` |
| Профи.ру | microsocks на входе слушает только `10.77.0.2:1080`; браузер аккаунта на основном ходит через него, Профи.ру видит адрес входа |
| Копии | пользователь `sara-backup`, папка `/srv/sara-backups/copies` |

На входе нет данных клиентов, кроме зашифрованных копий: ключ для
расшифровки лежит только на основном сервере.

Если адрес основного сервера заработает из России или появится новый,
вход можно убрать: вернуть `SARA_PUBLIC_DOMAIN`, `PROFI_ACCOUNTS` и
отключить `FRONT_TUNNEL_BIND` в `/opt/sara/.env`.
